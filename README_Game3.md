# Submarine Rescue - Game 3

This is my individual game contribution for the ELEC2645 Unit 4 group game console project.

The player controls a submarine using the joystick, rescues divers, avoids mines, manages oxygen, uses a sonar shield with BT2, and returns rescued divers to the base to score points.

Hardware used:
- STM32 Nucleo-L476RG
- ST7789 LCD
- Joystick
- BT2 / BT3 buttons
- PWM LED
- Buzzer

Controls:
- Joystick: move submarine
- BT2: sonar shield / restart
- BT3: return to main menu
